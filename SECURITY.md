# Security

Do not post credentials in issues. If you find a vulnerability, use GitHub private vulnerability
reporting when available; otherwise contact the repository owner privately without sharing secrets.

This package has no brokerage adapter, order execution service, tools for an LLM, or remote MCP surface.
API keys are read only for explicitly requested network narration. Reports contain the supplied
headlines, filing source and generated text; treat those files according to your data policy.
An external narrator receives the research snapshot and prior commentary. Do not send private data
without checking your provider's retention settings and terms. Ollama defaults to localhost.

Headlines and prior model messages are untrusted. Prompt isolation is defense in depth; the stronger
boundary is structural: model output has no code path back into the numeric allocation or backtest.
Models can still hallucinate or repeat malicious text. Review commentary before sharing it.
